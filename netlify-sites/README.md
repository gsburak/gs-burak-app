# Formatos publicados en Netlify

Estas carpetas son las copias maestras recuperables de los formatos externos de GS BURAK.

- `certificado`: fuente del certificado publicado en `stirring-semolina-e8a9e3.netlify.app`.
- `presupuesto`: fuente del presupuesto publicado en `magnificent-ganache-f9c37a.netlify.app`.

Antes de modificar o publicar cualquiera de los dos formatos:

1. Ejecutar `scripts/crear-respaldo.ps1`.
2. Modificar la copia maestra correspondiente.
3. Probar localmente.
4. Publicar en el proyecto de Netlify correcto.
5. Confirmar que el enlace público no cambió.
6. Guardar el cambio en GitHub.

No crear otro proyecto de Netlify para una actualización ordinaria; eso produciría un enlace distinto.
