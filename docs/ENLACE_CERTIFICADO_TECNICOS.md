# Acceso directo de técnicos

El administrador abre el certificado con su sesión habitual y pulsa «Obtener enlace para técnicos (sin contraseña)». Copia la dirección completa del cuadro y la comparte con su equipo. No debe compartir solo la dirección anterior al símbolo #.

El enlace es una credencial privada: cualquier persona que lo reciba puede consultar los clientes, productos y agenda operativa de esa administración, abrir certificados guardados y guardar reportes. No concede sesión en la aplicación principal ni acceso a gastos, compras, respaldos u otros formatos. Los certificados pueden contener datos personales capturados manualmente.

Cada administración tiene su propio enlace. Cambiar la contraseña del administrador invalida los enlaces anteriores; entonces se debe obtener y compartir el nuevo. Este cambio no modifica ninguna contraseña existente.

Los reportes nuevos se registran sin importes ni pagos; actualizar el reporte de un servicio existente conserva su información financiera. Se mantiene la comprobación de revisión antes de guardar y el guardado remoto existente de documentos y folios.

Validación: pruebas HTTP locales con datos ficticios de acceso, aislamiento por administración, documentos, bloqueo de respaldos y preservación de importes. No se modificaron registros de producción.
